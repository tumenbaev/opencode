Use this tool to make structured file edits with a single patch. The format is inspired by unified diffs, but with no line numbers. You must use the exact patch markers and headers, otherwise the patch will be rejected.

Every patch MUST start with following line:
*** Begin Patch

Every patch MUST end with following line:
*** End Patch

Paths within the project must be relative and outside the project must be absolute.

To update and/or move an existing file, use:

*** Update File: <path>
*** Move to: <new path>
@@
 <unchanged context lines prefixed by space>
-<old line>
+<new line>

Every update hunk MUST start with @@ line (without line numbers).
Context lines are optional and may include multiple lines.
`*** Move to:` is optional. If you include it, it must appear immediately after `*** Update File:` and before any line chunks. Always prefer `Move to` over `Delete+Add` for efficiency when doing refactoring.

To add a new file, use:

*** Add File: <path>
+<line 1>
+<line 2>

Every line in a new file must start with `+`.

To delete a file, use:

*** Delete File: <path>
